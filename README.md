### 📌 How to Submit an Issue

We appreciate your help in making BloomingChat better! Before submitting, please check the existing [Issues](../../issues) tab to avoid duplicates.

1. **Bug Reports:**
   - Go to the **Issues** tab and click **New Issue**.
   - Provide clear reproduction steps, your environment (Node version, OS, browser), and error logs/screenshots.
2. **Feature Suggestions:**
   - Have an idea or workflow you'd like to see? Open an issue labeled `enhancement`.
